# Factorial

GNU Bash 5.0.17 solution for computing `N!`.

## Approach

Initialize the answer to `1` and multiply it by every integer from `2` through `N`.

## Complexity

| Resource | Complexity |
|---|---:|
| Time | O(N) |
| Extra space | O(1) |

## Run

```bash
printf '2\n' | ./solution.sh
```

Expected output: `2`.
